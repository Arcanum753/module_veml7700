# module_veml7700 — люксметр VEML7700

> **Опциональный модуль.** Подключается через `src_filter` (define-флаг `MODULE_VEML7700`
> выводится из `src_filter` автоматически, в `build_flags` его указывать не нужно).
> **Работоспособен только в составе сборки, содержащей ядро** (см. `../../TRS.md` §2.1).

Датчик освещённости VEML7700 (I2C, адрес 0x10): чтение яркости в люксах, публикация
значения и доступности на шину `core_state`, настройка параметров датчика через web,
вывод значения в терминал (`lux`).

- **Репозиторий:** https://github.com/Arcanum753/module_veml7700
- **Папка:** `src/module_veml7700/`
- **Флаг активации:** `MODULE_VEML7700` (генерируется в `src/modules_defines.h` из `src_filter`)
- **Registry:** `object=module_veml7700`, `define=MODULE_VEML7700`, `namespace=veml7700`,
  `web=1`, `loop=0`, `res=1`
- **Env:** `esp32-veml7700`, `esp8266-veml7700`
- **Только для платформы:** обе (ESP8266/ESP32)
- **Зависит от ядра:** `core_web`, `core_sys`, `core_json`, `core_state`, `core_task`,
  `core_terminal`
- **Зависит от модулей:** — (в env добавлены `module_udp`, `module_otaclient` как в шаблоне)

## Назначение

Чтение VEML7700 по I2C (`Wire`, выводы по умолчанию: ESP32 21/22, ESP8266 4/5) и публикация
на шину **только** значения люксов и доступности датчика; настройки (усиление, время
интеграции, persistence, период опроса) — через веб-страницу. Режим `off/auto/macro`
не используется: если датчик доступен, значения доступны.

## Функциональные требования

- FR-VEML-1: Читать сырое значение ALS (регистр `0x04`) и пересчитывать в люксы по таблице
  разрешения (gain × IT).
- FR-VEML-2: Публиковать состояния `veml7700.lux` (F32) и `veml7700.available` (BOOL).
- FR-VEML-3: Периодический опрос через `core_task.every("veml7700_poll", …)` с периодом
  `pollInterval`; при сохранении настроек период переармируется.
- FR-VEML-4: Веб-интерфейс `veml7700.html` — показания в лк + настройки, сохранение без
  перезагрузки.
- FR-VEML-5: Терминальная команда `lux` — печать значения в лк, доступности, raw и параметров.
- FR-VEML-6: Конфиг `/config_veml7700.json`; bus-функция `veml7700.save` персистит конфиг.

## Аппаратные интерфейсы

| Интерфейс | Выводы по умолчанию | Примечание |
|-----------|---------------------|------------|
| I2C (VEML7700) | ESP32 21/22, ESP8266 4/5 (SDA/SCL) | `Wire` (общая шина, как у `module_ds3231`); адрес `0x10` |

## Веб-интерфейс

| Метод | URL | Назначение |
|---|---|---|
| GET | `/veml7700/info` | CVT: настройки + статус (доступность, lux, raw, насыщение) |
| GET | `/veml7700/read` | CVT: только показания (частый опрос) |
| POST | `/veml7700/save` | сохранить настройки, применить к датчику |
| GET | `/veml7700/ver` | версия модуля |

Страница `veml7700.html` (пункт меню — `web/_menu.html`), конфиг `web/config_veml7700.json`.

## Конфигурация

`/config_veml7700.json`:

```json
{"addr":16,"enabled":true,"gain":0,"it":2,"persistence":0,"pollInterval":1000}
```

- `addr` — I2C-адрес (0x10 = 16).
- `enabled` — при `true` `ALS_SD = 0` (датчик включён).
- `gain` — индекс 0..3: `x1`, `x2`, `x1/4`, `x1/8`.
- `it` — индекс 0..5: 25/50/100/200/400/800 мс.
- `persistence` — индекс 0..3: 1/2/4/8.
- `pollInterval` — период опроса, мс (мин. 200).

## Ресурсы шины (namespace `veml7700`)

- состояния: `veml7700.lux` (F32, ro), `veml7700.available` (BOOL, ro);
- функция: `veml7700.save` (→) — отложенное сохранение конфига.

`veml7700.available = true` только когда датчик найден на шине **и** включён (`enabled=true`).
При `enabled=false` публикуется `available=false` и `lux=0`, чтобы макросы не принимали
`0` за реальную освещённость.

Макросы читают значения через `cond` (`>`, `<`, `==`) — например порог по освещённости.

## Терминальные команды

| Команда | Назначение | Доступность |
|---------|-----------|-------------|
| `lux` | показать текущее значение в лк, доступность и параметры датчика | только `MODULE_VEML7700` |

## Слоистая структура

```
module_veml7700_types.h    — define'ы, структура конфига, карта регистров
module_veml7700.h          — класс CLASS_MODULE_VEML7700, debug-макрос, extern
module_veml7700.cpp        — шаблонный блок (begin, web_Init, ресурсы, конфиг, версии, терминал)
module_veml7700_engine.cpp — I2C, пересчёт raw→lux, pollStep, pollTask, deferredSaveTask, `lux`
module_veml7700.ini        — env-примеры + секция [registry]
web/                       — veml7700.html, _menu.html, config_veml7700.json
```

Локальный `common_module` не заводится: lux-конверсия параметризуется конфигом и нужна только
engine.

## Макросы

`web/macros/veml7700_brightness.lua` — пример сценария для `module_macros`: управляет яркостью
матрицы `device_electronica7_rgb` по освещённости (`<20 lx → 5`, `20..100 → 20`, `>100 → 35`).
При старте переводит `e7.mode` в `macro` (иначе запись `e7.brightness` отклоняется `ERR_DENIED`);
действует только при `veml7700.available == true`. В образ FS попадает в `/macros/` и
добавляется в список как **остановленный** — запускать через `/macros.html` или `macro run`.

## Ограничения

Точные позиции бит `ALS_PERS`/`ALS_IT`/`ALS_GAIN` и таблица разрешения должны быть сверены с
даташитом Vishay VEML7700 при доработке. Пороги (`ALS_WH`/`ALS_WL`) и прерывание (`ALS_INT_EN`)
не используются; авто-подбор gain/IT не реализован.

## Критерии приёмки

- AC-VEML: `esp32-veml7700`/`esp8266-veml7700` собираются; страница `veml7700.html`
  открывается; `/state/catalog` содержит `veml7700.lux` и `veml7700.available`; команда `lux`
  печатает значение.
